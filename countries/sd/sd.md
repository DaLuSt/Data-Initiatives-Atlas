# Sudan

## Description

Sudan (ISO 3166-1 alpha-2: **`SD`**) is a **base country anchor**. It carries the telecommunications regulator ([[SD-TPRA]]) and the law Telecommunications and Post Act 2018 ([[SD-TELECOM-POST-ACT-2018]]), from the regulator's own site; the law's text was not opened. The ministry's page was read through a fetch tool that returns a model's summary of the page; the Act's text was not opened. tpra.gov.sd answered HTTP 503.

Only the entities listed in [the country index](index.md). It is a first sourced slice, not a survey of the country's data governance (see `countries/README.md` on the participation model).
