# Chad

## Description

Chad (ISO 3166-1 alpha-2: **`TD`**) is a **base country anchor**. It carries the telecommunications regulator ([[TD-ARCEP]]) and the law Loi n° 007/PR/2015 on personal data protection ([[TD-LOI-007-2015]]), from the regulator's own site; the law's text was not opened. The regulator's pages were read through a fetch tool that returns a model's summary; the data protection Law is a scanned PDF whose pages 1, 3, 17 and 33 were read as images.
