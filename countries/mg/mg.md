# Madagascar

## Description

Madagascar (ISO 3166-1 alpha-2: **`MG`**) is a **base country anchor**. It carries the telecommunications regulator ([[MG-ARTEC]]) and the law Telecommunications Law 2005-023 ([[MG-LAW-2005-023]]), from the regulator's own site; the law's text was not opened. The Law was read in full as French text on a mirror, because the National Assembly's own copy answers HTTP 403; the regulator's site (artec.mg) answered HTTP 503, so the name ARTEC comes from press reports in search results.
