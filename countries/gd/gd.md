# Grenada

## Description

Grenada (ISO 3166-1 alpha-2: **`GD`**) is a **base country anchor**. It carries the Data Protection Act 2023 ([[GD-DPA-2023]]) and the Information Commission it provides for ([[GD-INFORMATION-COMMISSION]]). The text read is the Attorney-General's Data Protection Bill, 2023 on the Parliament's own site; that the Bill became the Act rests on titles seen in search results, not on a page the agent could open.
