# Zimbabwe

## Description

Zimbabwe (ISO 3166-1 alpha-2: **`ZW`**) is a **base country anchor**. It carries the Cyber and Data Protection Act ([[ZW-CDPA-2021]]), read as text, the regulator that the Act designates as the Data Protection Authority ([[ZW-POTRAZ]]) and the Act's 2024 regulations ([[ZW-SI-155-2024]]), all from the regulator's own site.

## What this anchor does not yet carry

Only the entities listed in [the country index](index.md). The Postal and Telecommunications Act [Chapter 12:05], the Cyber Security Centre the Act provides for, the regulations' text and the regulator's implementation guidelines (licensing of data controllers, consent, breach notification, cross-border transfers) were not read. It is a first sourced slice, not a survey of the country's data governance (see `countries/README.md` on the participation model).
