# El Salvador

## Description

El Salvador (ISO 3166-1 alpha-2: **`SV`**) is a **base country anchor**. It carries the personal data protection law, the Ley para la Protección de Datos Personales (Decreto No. 144) ([[SV-LEY-PDP-2024]]), the State Cybersecurity Agency it names ([[SV-ACE]]) and the Cybersecurity Law it relies on ([[SV-LEY-CIBERSEGURIDAD-2024]]). The personal data Law was read from page images of the Diario Oficial issue (a scanned PDF with no text layer; pages 1, 2, 4 to 7, 24, 34, 35, 39 and 40 of 40 were opened).
