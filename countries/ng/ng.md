# Nigeria

## Description

Nigeria (ISO 3166-1 alpha-2: **`NG`**) is a **base country anchor**. It carries the Nigeria Data Protection Act 2023 ([[NG-NDPA-2023]]), the Nigeria Data Protection Commission ([[NG-NDPC]]) and the Commission's General Application and Implementation Directive of 2025 ([[NG-NDPA-GAID-2025]]), all from the Commission's own site; the Act's text was not read.

## What this anchor does not yet carry

Only the entities listed in [the country index](index.md). It is a first sourced slice, not a survey of the country's data governance (see `countries/README.md` on the participation model).
