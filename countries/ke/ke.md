# Kenya

## Description

Kenya (ISO 3166-1 alpha-2: **`KE`**) is a **base country anchor**. It is here because the Atlas models Kenya's Data Protection Act and the Office of the Data Protection Commissioner that it establishes.

## What this anchor does not yet carry

Only the entities listed in [the country index](index.md). It is a first sourced slice, not a survey of the country's data governance (see `countries/README.md` on the participation model).
