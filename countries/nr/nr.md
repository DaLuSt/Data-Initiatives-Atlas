# Nauru

## Description

Nauru (ISO 3166-1 alpha-2: **`NR`**) is a **base country anchor**. It carries the telecommunications regulator ([[NR-NCA]]) and the law Communications and Broadcasting Act 2018 ([[NR-COMMUNICATIONS-BROADCASTING-ACT-2018]]), from the regulator's own site; the law's text was not opened. The Act's WIPO Lex page was read through a fetch tool that returns a model's summary (the first 100,000 of 130,000 characters); the PacLII copy answered HTTP 503 and was not opened.
