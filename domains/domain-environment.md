# Environment

## Description

Classification node for environmental protection and waste management.
Created 2026-09-25 at the user's request to add domains reflecting the
sector list in the Dutch Cyberbeveiligingswet (Cbw) — "Afvalstoffenbeheer"
is one of the seven important-entity sectors in the Cbw's own Bijlage 2,
confirmed by reading `ncsc.nl`'s "Valt mijn organisatie onder de
Cyberbeveiligingswet (NIS2)?" page directly (2026-09-25), which lists the
same seven sectors as Directive (EU) 2022/2555's (NIS2) Annex II. This is
the slug already anticipated (unused until now) in
`metadata/taxonomy.md` §1.3.

Like [[DOMAIN-GOVERNMENT]], this is a taxonomy node rather than a
researched entity: it carries no factual claims and therefore no sources.
The sourced claim that Waste management is an important sector lives on
[[NL-CBW]] and [[EU-NIS2]], not here.

## Relationships

Used by [[NL-CBW]] and [[EU-NIS2]] (important-sector scope), and by
[[EU-GREEN-DEAL-DATA-SPACE]], one of the common European data spaces,
intended to integrate cross-sectoral data in support of European Green
Deal priority actions.
