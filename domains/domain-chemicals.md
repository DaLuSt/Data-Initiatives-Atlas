# Chemicals

## Description

Classification node for the chemicals sector. Created 2026-09-25 at the
user's request to add domains reflecting the sector list in the Dutch
Cyberbeveiligingswet (Cbw) — "Chemische stoffen" is one of the seven
important-entity sectors in the Cbw's own Bijlage 2, confirmed by reading
`ncsc.nl`'s "Valt mijn organisatie onder de Cyberbeveiligingswet (NIS2)?"
page directly (2026-09-25), which lists the same seven sectors as
Directive (EU) 2022/2555's (NIS2) Annex II.

Like [[DOMAIN-GOVERNMENT]], this is a taxonomy node rather than a
researched entity: it carries no factual claims and therefore no sources.
The sourced claim that Chemicals is an important sector lives on
[[NL-CBW]] and [[EU-NIS2]], not here.
