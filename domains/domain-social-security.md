# Social Security

## Description

Classification node for the social security sector. It was anticipated in
`metadata/taxonomy.md` §1.3 and created on 2026-10-03, once it connected two
entities, meeting the threshold in `domains/README.md`: [[BE-KSZ]] and
[[BE-KSZ-WET]].

It exists because `level: sectoral`, which used to carry the KSZ's sector, was
retired the same day (`metadata/ontology.md` §4) and the KSZ's sector then had
nowhere in the structured data. Both entities also keep
[[DOMAIN-GOVERNMENT]].

Like [[DOMAIN-GOVERNMENT]], this is a taxonomy node rather than a researched
entity: it carries no factual claims and therefore no sources.

## Relationships

Used by [[BE-KSZ]] and [[BE-KSZ-WET]].
