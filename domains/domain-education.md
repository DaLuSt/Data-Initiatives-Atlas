# Education

## Description

Classification node for the education sector. Created in Batch 5 now that it
connects two entities, meeting the threshold in `metadata/taxonomy.md` §1:
[[NL-SURF]] and [[NL-ROSA]].

It was deliberately withheld in Batches 2 and 4 — when it would have
connected only one entity each time — and both affected entities carried a
note explaining the gap. Those notes are now resolved.

Like [[DOMAIN-GOVERNMENT]], this is a taxonomy node rather than a
researched entity: it carries no factual claims and therefore no sources.
