# Built Environment

## Description

Classification node for the built-environment sector. It was created on
2026-10-03, once it connected two entities, meeting the threshold in
`domains/README.md`: [[NL-DIGIGO]] and [[NL-DSGO]].

It exists because `level: sectoral`, which used to carry the sector of both
entities, was retired the same day (`metadata/ontology.md` §4) and neither had
a domain that fitted. [[NL-DIGIGO]] also keeps [[DOMAIN-GOVERNMENT]].

Like [[DOMAIN-GOVERNMENT]], this is a taxonomy node rather than a researched
entity: it carries no factual claims and therefore no sources.
