# domains/

Entities of `type: domain` — subject-matter domains (Mobility, Health,
Government, ...) used to classify other entities via their `domains:`
frontmatter field. See `metadata/taxonomy.md` §1 for the anticipated domain
list and slug conventions. Only create a domain entity when it actually
connects two or more other entities.

Filename: `<id-lowercased>.md`, e.g. `domain-mobility.md`. Template:
`templates/entity-template.md`.
