# publications/

Entities of `type: publication` — reports or studies with independent
significance. Per README §25, publications should generally *support* other
entities via `sources:`/`references` rather than become entities themselves;
only add one here when it has standing of its own (e.g. a foundational
report that other initiatives explicitly build on).

Filename: `<id-lowercased>.md`. Template: `templates/entity-template.md`.
