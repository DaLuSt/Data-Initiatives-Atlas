# international/

One sub-folder per international system/body treated as an anchor,
`international/<code-lowercase>/`, holding that anchor entity plus a curated
`index.md` (`metadata/ontology.md` §3.1). International-level entities live
in their type folder, tagged with `level: international`.

## Anchors

| Body | Code | Folder |
|---|---|---|
| United Nations | UN | [`un/`](un/) |
