# BS 10012:2017+A1:2018 — a British Standard for personal information management

> **Created 2026-10-15** (roadmap #459, the British Standard item). Sourced from BSI's own catalogue page, read directly. The standard's text was not read (it is sold), only BSI's description of it.

## Description

BSI's page: "BS 10012 specifies requirements for a personal information management system (PIMS), which provides a framework for maintaining and improving compliance with data protection requirements and good practice." It is for "those responsible for planning, establishing, implementing, and maintaining a PIMS within an organization". The 2017 edition with the 2018 amendment "supersedes BS 10012:2017, which is withdrawn"; "requirements have been revised in line with the European Union General Data Protection Regulation 679/2016" ([[EU-GDPR]]), and "the structure has been updated to follow the ISO management system structure". Classified under ICS 01.140.30 and 03.100.99; the committee is BSI's IDT/1.

## Withdrawn on 24 April 2026

The catalogue shows "Standard Withdrawn" with "Published: 31 Jul 2018 • Withdrawn: 24 Apr 2026". The page names no replacement, so `status: archived` and no `successor`. Why it was withdrawn, and whether a new edition or an ISO standard (for example the ISO/IEC 27701 privacy extension) takes its place, was not found.
