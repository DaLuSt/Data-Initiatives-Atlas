# initiatives/

Entities of `type: initiative` — named efforts that don't fit a more
specific type (`policy`, `strategy`, `programme`, etc.). Any geography,
identified by `level`/`country`/`region`, not by sub-folder.

Filename: `<id-lowercased>.md`. ID format and placement rule:
`metadata/ontology.md` §2–3. Template: `templates/entity-template.md`.
