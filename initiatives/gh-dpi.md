# Digital Public Infrastructure Initiative (Ghana)

> **Created 2026-10-16** (roadmap #481, Ghana). Read on NITA's page. It is a description of an initiative with no start date, budget or status stated on the page; what has actually been deployed (for example X-Road) is **not** established by it.

## What the page says

Three pillars: **Digital identity** (Ghana Card; biometric authentication standards, universal enrolment, API integration for the private sector); **Digital payments** (interoperable routing; QR adoption, real-time gross settlement, government-to-citizen disbursements, GhIPSS and mobile money); **Data exchange** ("Secure, consent-based registries and X-Road architecture": X-Road implementation, consent management frameworks, the once-only principle). Alignment with UN definitions and safeguards for DPI; principles named include inclusivity.
