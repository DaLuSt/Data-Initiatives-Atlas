# Loi n° 2017-20 du 20 avril 2018 portant code du numérique en République du Bénin

> **Created 2026-10-11** (roadmap #471, Benin). Only a citation on the Presidency's privacy page was read; the Code itself was not, so this entity says nothing about its contents.

## What is sourced

The government's site names the Code by number, date and title and ties it to the data-protection authority: the site was declared to the Autorité de Protection des Données à caractère Personnel ([[BJ-APDP]], `apdp.bj`) "conformément à la loi n° 2017-20 du 20 avril 2018 portant code du numérique", and users with a complaint can address "une plainte ou une demande auprès de l'Autorité de Protection des Données à caractère Personnel". The same page sets a retention limit of 24 months for the Presidency's own forms.

## What was not read

The Code's text (the personal-data book that creates the authority), any amending law, the Official Gazette, and the authority's own site (`apdp.bj` is a JavaScript shell for the agent and the runner). Secondary sources mention an amending law of 6 January 2021; it is not recorded here.
