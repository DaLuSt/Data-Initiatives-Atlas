# legislation/

Entities of `type: act`, `regulation`, `directive`, `decision`,
`subordinate-legislation` or `agreement`. See
`metadata/taxonomy.md` §2 for how `type` + `level` + `country`/`region`
together distinguish EU regulations, EU directives, Dutch implementation
legislation and Dutch national legislation.

Filename: `<id-lowercased>.md`. Template: `templates/entity-template.md`.
