# Model Information Code for the CIS Member Nations (2012)

> **Created 2026-10-14** (roadmap #543). Known **only** from one sentence of the Assembly's own article of 20 November 2017, read on a GitHub runner. **The Code's text, its number and what it covers were not read**, so nothing about its content is recorded.

## What is sourced

Among "three model codes" adopted by the Interparliamentary Assembly on the proposal of its Joint Board of Experts with the Regional Commonwealth in the Field of Communications: the Model Intellectual Property Code (7 April 2010), the Model Information Code for the CIS Member Nations (23 November 2012) and the Model Code of Innovations (28 November 2014). Model laws of the Assembly "are recommendatory" and are submitted to national parliaments, so this is `soft-law`. Which member states, if any, used it was not found.
