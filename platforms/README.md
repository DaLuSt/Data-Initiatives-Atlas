# platforms/

Entities of `type: platform` or `type: technology` — concrete technical
platforms/systems and named technologies/protocols referenced by other
entities. Not present in the original README diagram; added in Batch 0 to
give these two ontology types (README §"What is being mapped?") a home. See
`metadata/ontology.md` §6 (design decisions).

Filename: `<id-lowercased>.md`. Template: `templates/entity-template.md`.
