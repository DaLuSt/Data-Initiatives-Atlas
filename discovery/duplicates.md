# Suspected Duplicates

Pairs/groups of entities that might represent the same real-world thing.
Record here rather than silently merging, so the merge decision (which ID
survives, which becomes `status: superseded` with a `successor`, or whether
they're genuinely distinct) is deliberate and reviewable.

This page uses the same master-table layout as `discovery/unresolved.md`
(one table, sorted by area; resolved rows are deleted, not struck through;
row IDs are `D1`, `D2`, … and are not renumbered when a row is removed).
