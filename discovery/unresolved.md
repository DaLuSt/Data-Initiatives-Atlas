# Unresolved

Open questions the Atlas cannot currently answer with confidence: a fact
that couldn't be verified, a relationship that seems plausible but isn't
directly sourced, a status that couldn't be confirmed. Never guess to close
one of these — resolve it with a real source, or leave it open.

**Format note (2026-09-06):** this file used to be organised as ~30
per-batch sections, each with its own small table plus narrative. It has
been restructured into one master table, sorted by area, so the whole
list can be scanned or searched at once. Closed/resolved rows are kept
(not deleted) as a record of how each question was settled, matching the
project's existing convention. The batch-by-batch prose retrospectives —
what was checked, what got promoted, which sources turned out to be
blocked — have been condensed into the reference sections after the table
rather than dropped entirely, since some of that (confirmed domain blocks,
the ontology-level findings) is still operationally useful. Full narrative
detail for any specific past pass remains in git history.

**Restructuring found one big stale item while consolidating**: the
original Batch 1 row below claimed 389 of 396 entities were still
`verification: search-only`. A fresh repo-wide check (2026-09-06,
`grep -rl "^verification: search-only"`) found **zero** — every entity in
the Atlas now carries `verification: primary-source`. The ~20
re-verification passes logged in the old version of this file over
2026-08-27 to 2026-09-05 finished the job; the row was simply never closed
out. It is closed below.

## Ontology and vocabulary findings (context, not a per-item queue)

These cut across many rows above rather than belonging to one entity. Kept
here as a compact reference; the individual affected rows above carry the
`Open` status and area.

- **No sub-national `level`.** See item #5 — the single highest-value
  finding of the whole project. Confirmed lossy for Germany, Belgium and
  Spain independently; `level: subnational` exists in the schema since
  2026-08-21 but Germany's and Spain's own sub-national bodies remain
  unmodelled.
- **The relationship vocabulary has almost no way to express how data
  moves**, only what entities *are* and *descend from*. Five to seven
  sourced connections sit unmodelled for want of a type (items #12, #13) —
  past the two-example threshold `metadata/relationship-types.md` §2.3
  sets for proposing one, still not proposed.
- **Legislative rank is flattened.** `type: law` cannot distinguish organic
  from ordinary law (Spain), Act from statutory instrument (Ireland), a
  Joint Committee Decision filed alongside ordinary statutes (Norway/EEA),
  or binding treaty from non-binding recommendation (UN). See item #11 —
  a genuinely large taxonomy change, not attempted on partial evidence.
- **A record that was wrong for three batches** (UN batch, 2026-08-16):
  "no national statistical office connects upward to Eurostat" was
  repeated in this file, `candidates.md`, and three batch entries, when
  [[NL-CBS]] already had the edge from an early batch. The lesson kept
  from that pass: cluster narratives in this file are prose, and prose
  does not get validated — carried into this restructuring by preferring
  a single checkable table over duplicated narrative claims.
- **The country-neutral EU-instrument model held up.** Belgium, France,
  Spain, Poland and every subsequent country batch required no ontology,
  schema, folder, validation or generator change — the federal `level`
  gap above is the one real defect the model has, not a general
  country-shape problem.
