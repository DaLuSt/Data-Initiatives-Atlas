# regions/

One sub-folder per participating region, `regions/<code-lowercase>/`, each
holding the `region` anchor entity plus a curated `index.md`
(`metadata/ontology.md` §3.1). Region-scoped entities live in their type
folder, tagged with `region: <CODE>`.

## Participating regions

| Region | Code | Folder |
|---|---|---|
| European Union | EU | [`eu/`](eu/) |
